# Realms of Myth — Custom Particle & Fog IDs

All custom VFX live in `realms_of_myth_RP/particles/*.particle.json` with
textures in `realms_of_myth_RP/textures/particles/` (generated by
`texture-sources/gen_particles_aaa.py`).

Fogs live in `realms_of_myth_RP/fogs/`.

## Dragon breath particles (wired into RP client entities)

| Particle ID | Wired into | How |
|---|---|---|
| `realms:dragon_breath_fire` | `RP/entity/dragon_fire.entity.json` → `particle_effects.breath_fire`; `RP/animations/dragon_fire.animation.json` `animation.dragon_fire.breath` timeline @0.25s | Fires when breath animation plays |
| `realms:dragon_breath_frost` | `RP/entity/dragon_frost.entity.json` → `particle_effects.breath_frost`; same animation file, `animation.dragon_frost.breath` @0.25s | Fires when breath animation plays |
| `realms:phase_enrage` | both dragon entities as `particle_effects.enrage` | Available via `/particle realms:phase_enrage` from dragonBoss.js phase-change code |

Scripts can also trigger directly:
`player.runCommand('particle realms:fireball_trail ~~~')` or
`dimension.spawnParticle('realms:arcane_step', location)`.

## Fogs

| Fog ID | File | Mood | Suggested use |
|---|---|---|---|
| `realms:dragon_lair_fog` | fogs/dragon_lair_fog.json | Ominous red-tinged, short range (48 blocks) | Fire-dragon lair biome/boss arena; apply while a fire dragon is engaged nearby |
| `realms:frost_domain_fog` | fogs/frost_domain_fog.json | Cold blue, long range (128 blocks) | Frost dragon domain / frozen zone |

Apply client-side per-player via fog commands (`/fog @s push realms:dragon_lair_fog dragon`) from scripts.
